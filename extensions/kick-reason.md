# Kick Reason

| ------------: | ------------ |
| Extension ID: | 194          |
| Version:      | 1            |
| Type:         | `PACKETLESS` |

Send a [Chat Message](../protocol075.md#chat-message) with type 2 (CHAT_SYSTEM) and player id 255, before
kicking a player out of the server.

See [Extensions](extension.md) for how the extension is negotiated.
